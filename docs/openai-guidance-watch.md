# OpenAI運用ガイドの重要変更を確認する

状態：登録用の指示を準備済み。定期実行・通知は未登録、未検証（2026-09-06）。本セッションにスケジュール登録ツールはない。

## 現在の基準

| 確認先 | 2026-09-06時点で確認した基準 |
|---|---|
| [Astra公式ガイド](https://developers.openai.com/api/docs/guides/latest-model) | 自律的完遂、指示の衝突監査、委譲条件の明示、必要十分な検証 |
| [WorkとCodex](https://help.openai.com/en/articles/20001275/) | 用途・利用枠は製品別。Astraの消費量は仕事・推論設定等に依存 |
| [モデル提供状況](https://help.openai.com/en/articles/20001354) | 提供範囲はプランと段階展開に依存。モデル別の職種固定はしない |
| [定期タスク](https://learn.chatgpt.com/docs/automations) | 対応するWeb・デスクトップから管理。CLIには管理画面がない |

これは公開情報の基準であり、利用者のプランや利用可能モデルを確認した記録ではない。

## 登録用の指示

ChatGPTの定期タスクに対応するチャットへ、以下を貼り付ける。頻度は毎週月曜9時（日本時間）を初期案とする。

```text
毎週月曜9:00（Asia/Tokyo）に、このチャットでOpenAI公式ガイドの重要変更を確認してください。

対象：
https://developers.openai.com/api/docs/guides/latest-model
https://help.openai.com/en/articles/20001275/
https://help.openai.com/en/articles/20001354
https://learn.chatgpt.com/docs/automations
対象ページから関連するOpenAI公式更新情報を確認して構いません。

運用の基準：短い共通ルールを使い、可逆的な作業を完成・検証まで自律実行する。
承認が必要な操作は直前まで準備する。独立した成果物は権限と完成条件を付けて委譲し、親が統合する。
モデル・推論量・並列数は仕事に合わせ、必要十分な調査・検証を行う。

初回は取得日・対象モデル・製品・関連節の要約をこのチャットに保存して比較基準とし、変更通知扱いにしない。
以後は直前に正常取得できた基準と意味の差分を比較する。ページ全体の更新日時やハッシュだけで判定しない。
通知対象は、自律性・承認・委譲・検証の推奨変更、利用中の運用に影響する廃止・非互換・権限変更とする。
価格や利用枠は、モデル選択の見直しにつながる公式変更だけを対象とする。
宣伝、表現修正、ベンチマーク更新だけでは通知しない。既に通知した同じ変更は繰り返さない。
変更が確認できた場合だけ、日本語で「変更点／現行運用への影響／最小修正案／適用条件／公式URL・確認日」を簡潔に知らせる。
公式記述、推測、この利用者への適用が未確認の点を区別する。設定・ルールの自動編集や第三者への送信は行わない。
取得失敗を「変更なし」にしない。失敗時は基準を更新せず、同じ参照先が2回連続で取得できなければ監視障害として知らせる。
比較基準を参照できない場合は、その事実を示して基準を再作成し、変更を推測しない。
重要変更がない回は通知を省略する。実行基盤で通知抑制ができない場合は、その制約を明示する。
```

## 登録後の確認

Scheduled画面で登録名・実行時刻・次回実行を確認し、初回を手動実行して基準保存と通知先を確かめる。重要変更なしの回が通知されないことも実際の出力で確認する。登録成功と通知抑制の実測が揃うまでは「監視稼働中」と報告しない。

Webの定期タスクはローカルのSD003を直接読めないため、必要な基準は上の指示と同じチャット内に保持する。詳細は[公式の定期タスクガイド](https://learn.chatgpt.com/docs/automations)を参照。
