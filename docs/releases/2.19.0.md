# SD003 Framework 2.19.0

公開日: 2026-09-05。deployツールの版番号は3.5.0。

## 変更

- Codexの固定担当・形式的な確認・画面やクイズの一律要求を解除。利用可能なツールと必要な検証で依頼を完了する。
- 独立した作業のサブエージェント利用を許可。モデル・推論量はユーザーの選択を尊重する。
- sessionreadは最新引継ぎとGit状態を基本にし、全履歴の読み込みと保守作業の自動起動を撤去する。
- 原資料と未コミット変更の保護、公開・GAS deployment変更の承認条件は維持する。
- Codexの編集手順に必要な`lead-lock.ps1`を配布し、欠落を配布検証で検出する。
- `.sd003-keep`をセッション・協調文書のテンプレート、廃止物の退避にも適用する。保護された子ファイルがあるディレクトリは退避しない。
- Skill再生成の出力先に保護指定がある場合は配布後の一括再生成を省略し、保護対象を維持する。

## 配布と更新

配布元はこの版のGitコミットから作成したソースZIP。未追跡ファイル・個人用config・認証情報は含めない。
ZIPを展開し、その中の`.claude/skills/sd-upgrade/upgrade.ps1`を`pwsh -NoProfile`で実行する。
最初に対象を指定したdry-runを行い、固有変更を`.sd003-keep`で保護してから`-Execute`で更新する。
既存の引継ぎ・仕様・業務データを維持し、内容検証と今回のCodex入口・sessionreadの反映を確認する。

`CLAUDE.md`を保護しているプロジェクトでは、その中の旧版表記を更新済みの証拠に使わない。実際に配布したファイルと配布記録で判断する。
起動済みセッションに注入済みの旧指示が残る場合は、新しいセッションで入口とSkillを読み込む。

## この版に含めない変更

ガードの文字列誤検知・相対パス判定、実行基盤のレビュー合否判定は、この版では修正していない。
モデルの性能比較やGAS本番反映を配布検証の代わりにはしていない。
