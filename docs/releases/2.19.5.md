# SD003 Framework 2.19.5

更新日: 2026-09-23。deployツールの版番号は3.5.0のまま。既存プロジェクトは`/sd-upgrade .`で取り込む。

## 変更内容

公式「Prompting Claude Opus 5.5」「Prompting Claude Opus 5」（platform.claude.com）に合わせ、思考・検証を促す旧指示を削った。

- `/bug-trace`: Step 2.5 の「Ultrathink Synthesis (MANDATORY)」「Use extended thinking (ultrathink)」を削除し「Synthesis」に改名。3エージェント結果の突き合わせと出力形式は維持。分析の深さは effort で調整する。
- `parallel-subagents` スキル: 廃止済みの「サブエージェント積極活用原則」を削除。判断フローの先頭に「数回のツール呼び出しで済むなら委譲しない」を追加。パターン3（型チェック・Lint・テストのサブエージェント並列）を Bash の並列呼び出しに変更。「自分の作業の検証のためのAgent起動」を禁止事項に追加。
- `.claude/rules/ui/web-design-principles.md`: 禁止事項に Opus 5.5 の既定スタイル5つ（クリーム系・オフホワイト背景、見出しのイタリック強調、「01/02/03」番号ラベル、等幅ラベル、ピル型ボタン）を追加。
- `templates/user-claude.md.template`（新規マシンの `~/.claude/CLAUDE.md` 初期値）: 「常に plan mode」「Challenge changes」「検証をサブエージェントに任せる」「Opus with thinking mode」を削除（sd003 本体は 2026-07-26 に削除済みで、テンプレートだけ残っていた）。effort で思考量を調整する旨を追加。
- `templates/AGENTS.md.template`: 同じ旧条項を削除。サブエージェントは明示依頼時のみ、自分の作業の検証に使わない（2026-09-20 の Codex 側裁定と一致）。

## 配布対象外（各マシンで手動）

- `~/.claude/settings.json` の `modelSettings` に `"claude-opus-5-5": {"effortLevel": "medium"}` を追加する。公式は Opus 5.5 を medium から始め、xhigh/max は品質向上を測定できた作業に限るよう勧めている。全体の `effortLevel` が `xhigh` のままだと Opus 5.5 は xhigh で動く可能性がある。
