# SD003 Framework 2.19.1

公開日: 2026-09-05。deployツールの版番号は3.5.0。

2.19.0のCodex手順・sessionread・配布保護の改善を含む最終配布版。

## 互換性修正

`.sd003-keep`で全体を保護しているファイル・フォルダは、更新前バックアップへ重複コピーしない。
Windowsで保護対象の古いアーカイブに予約名`nul`があると、従来の無条件コピーが失敗し、更新処理を開始できなかった。
更新しない保護対象は原位置に維持し、更新するフレームワークのバックアップは従来どおり取得する。

2.19.0を適用済みの場合は、配布スクリプト・そのSkillとテンプレートの差分更新で対応できる。Codex入口とsessionreadの内容は2.19.0から変わらない。

## 検証と利用

PowerShell/Bashの保護対象保持と非保護対象バックアップを隔離環境で確認する。配布ZIPは確定Gitコミットから作成する。
新規導入はZIP内の`sd-deploy`、既存導入はZIP内の`sd-upgrade`を使う。最初にdry-runで固有変更と保護指定を確認する。

2.19.0の変更内容と保護設定を残す場合の注意は`docs/releases/2.19.0.md`を参照。
保護したCLAUDE.mdや過去記録の旧版表記はそのまま残る。実ファイルと配布記録を更新版の根拠とする。
